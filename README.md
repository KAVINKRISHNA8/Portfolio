## 🛠️ Getting Started

### 1. Prerequisites
Ensure you have [Node.js](https://nodejs.org/) installed (v18 or newer).

### 2. Run Locally in Development Mode
```bash
# Start Vite development server
npm run dev
```
Open your browser at `http://localhost:3000`.

### 3. Build for Production
```bash
npm run build
```
This generates an optimized static bundle in the `dist/` directory ready for 1-click deployment.

## 🌐 Deploy to Vercel (1-Click Deployment)

This portfolio is ready for instant deployment to [Vercel](https://vercel.com):

1. Initialize git and push to GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: initial portfolio release for Kavinkrishna MS"
   git branch -M main
   git remote add origin https://github.com/KAVINKRISHNA8/Portfolio.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository `portfolio`.
4. Framework preset will automatically detect **Vite**.
5. Click **Deploy**!
